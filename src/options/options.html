Extrator NFCe Nota Paraná

Endereços

A extensão só atua nestas páginas (incluindo o que vier depois do caminho). Ao salvar um domínio novo, o Firefox pede permissão para acessá-lo.

Estabelecimentos

Um por linha, no formato CNPJ=Tipo. Tipos: Mercado ou Meal. Linhas iniciadas com # são comentários. Também dá para cadastrar direto pelo painel de diárias.

Itens não alimentícios

Itens cuja descrição tem uma palavra começando com estes termos já vêm desmarcados. Um termo por linha; # para comentários.

Valor

Sistema interno

Prioridade usada ao preencher o formulário de Reembolso de Diária.

Backup

Remover a extensão apaga as configurações. Exporte para um arquivo e importe depois de instalar de novo. A fila de diárias não entra no backup.
